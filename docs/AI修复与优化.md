# AI 全扩展修复与优化（v0.16.1）

2026-10-09。针对单机全 AI、20 个扩展同时开启后停在“思考中”的问题。

## 原因与修复

| P | 缺陷 | 实现 |
|---|---|---|
| P0 | 塔抓捕只寻找第一个对手，多人局抛出 StopIteration | 按捕获节点实际随从所属颜色筛选全部对手 |
| P0 | 传送门用当前地牌段号评估远端地牌，IndexError；执行遗漏 pos | 根据实际节点元数据估值，所有入口提交完整部署选项 |
| P0 | 素材生成只覆盖早期扩展，遇到缺失 PNG 中断 Tk 回调 | 使用全部牌面注册表生成；缺图时回退程序绘制 |
| P0 | AI 异常后无下一次回调 | 规划与提交分离；失败动作回滚；合法中性动作降级；不可恢复时明确暂停 |
| P0 | AI 验证仅两人且跳过真实特殊动作 | 单机/联机/验证共用 ai_turn；45 局全扩展矩阵与真实 Tk 异步验证进入发布门禁 |
| P1 | 幽灵消耗普通供给、大型骑士脱困归还到普通池 | 独立幽灵步骤与供给筛选；大小/幽灵按类型归还 |
| P1 | 特殊阶段使用回合玩家而非实际行动者 | 引擎 decision_player 统一龙、伯爵、城堡、拍卖、怪圈、强盗、瘟疫行动者 |

真实 Tk 验证发现的缺图问题，是纯规则测试无法覆盖的第三条直接卡住路径。
塔的人质及伯爵城未移入随从在终局可留在原处；守恒断言将它们计入总量，不改变规则。

## 优化实现

| P | 优化 | 实现 |
|---|---|---|
| P1 | 正确的模拟副本 | 复制完整可变规则状态与并查集，复用不可变地牌，保留 RNG 与特征别名；前瞻在下次隐藏抽牌前停止 |
| P1 | 界面响应 | 后台线程只规划独立副本，Tk 主线程提交；暂停/关闭取消任务，状态变化后丢弃过期结果 |
| P1 | 思考时间 | 可配置预算；候选间及模拟阶段检查超时/取消，保留已评估合法动作 |
| P1 | 落点计算 | 棋盘维护边界空格，引擎缓存落点与对应木桥补救方案 |
| P2 | 增量绘制 | 地牌静态项保留，仅追加新牌；图元层按变化重绘 |
| P2 | 观战 | 顶部暂停/继续/单步；菜单播放速度、思考时间、跟随落牌；提示显示阶段与上次选步耗时 |
| P2 | 策略 | 道路完成分值、相同特征根去重、农场毗邻城市去重与虚拟连接估值；真实部署使用规则引擎估值 |

AI 诊断保存在用户目录 `.carcassonne/diagnostics`，包含异常堆栈、公开快照及可重放存档。
`build_release.py` 生成本地发布包；GitHub 上传通过独立发布操作完成。
